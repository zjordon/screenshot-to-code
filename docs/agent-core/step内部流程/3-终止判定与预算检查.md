# Phase 3: 终止判定与预算检查

> 对应 `_run_with_session` 每轮迭代的中段（engine.py:264-276）。

## 📋 Phase 概述

循环的"岔路口"：模型本轮不调工具 → 走终结化路径跳出循环（正常完成）；还要继续 → 先过预算熔断，超 $3 即枪毙该变体。

### 🔄 主要逻辑流程

#### 1️⃣ **无工具调用的终结化路径** (第 264-265 行)
```python
if not turn.tool_calls:
    return await self._finalize_response(turn.assistant_text)
```
- `_finalize_response`（L375-386）优先取 file_state.content；正文 HTML 只是兜底。

#### 2️⃣ **预算熔断检查** (第 267-276 行)
```python
spent = session.total_cost_usd()
if spent is not None and spent > GENERATION_MAX_COST_USD:
    raise BudgetExceededError()
```
- 检查点在"无工具判定"之后——最终轮已付费不再拦截；未定价模型返回 None 不设限。

### 🔄 数据流

```
ProviderTurn
  │
  ├── tool_calls 为空 ──→ _finalize_response ──→ 返回 HTML（循环出口 A）
  │
  └── 有工具调用
        ├── spent = None（未定价）──→ 继续 Phase 4
        ├── spent ≤ $3.0          ──→ 继续 Phase 4
        └── spent > $3.0          ──→ BudgetExceededError（循环出口 B）
```

## 返回值

路径 A 返回最终 HTML str；路径 B 抛异常上浮至编排层翻译为 variantError。

## 总结

1. 🎯 "已付费不拦截"的边界设计——熔断只阻止未来的花费，不浪费已发生的产出
2. 💰 未定价模型返回 None 是一等语义，熔断自动让位
3. 🔀 两类出口语义不同：A 是成功（可 EmptyOutput 兜底），B 是失败（eval 不重试）
