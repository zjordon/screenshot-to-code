# Phase 6: 运行收尾

> 对应 `AgentEngine.run()` 的 try/except/finally 段（engine.py:354-373）。

## 📋 Phase 概述

循环结束后的三岔收尾：成功则落盘 completed 档案并返回 HTML；空输出升级为 EmptyOutputError；任何异常（含客户端取消）经 BaseException 兜底落盘 failed；finally 无条件关闭会话。

### 🔄 主要逻辑流程

#### 1️⃣ **成功收尾与空输出判定** (第 354-360 行)
```python
result = await self._run_with_session(session)
if not result:
    raise EmptyOutputError()
if self.recorder is not None:
    await self.recorder.record_run_end("completed", final_html=result)
return result
```
- 空串是"看起来成功的失败"——升级为异常走失败收尾。

#### 2️⃣ **异常兜底与会话关闭** (第 361-373 行)
```python
except BaseException as exc:
    ... record_run_end("failed", error=...)
    raise
finally:
    await session.close()
```
- BaseException 覆盖 CancelledError（客户端断开）；finally 保证用量日志与网络释放。

### 🔄 数据流

```
_run_with_session 返回/抛出
  │
  ├── str 非空 ──→ record_run_end(completed) ──→ return HTML
  ├── str 空    ──→ EmptyOutputError ──┐
  └── 异常      ─────────────────────┤
                                    ▼
                    except BaseException:
                      record_run_end(failed, error)
                      raise（向上传播）
                                    │
                    finally: session.close()（必然执行）
```

## 返回值

成功路径返回最终 HTML str；失败路径异常上抛至 `_run_variant`（翻译为 variantError）或 eval runner（按类型决定重试）。

## 总结

1. ✅ 空输出判失败保护评测（对应提交 91c400f——空文件曾让 diff 模式永久跳过）
2. 🛑 BaseException 兜底让取消也闭环——run 记录永不悬挂
3. 🔒 finally 是网络资源与用量日志的唯一保证
