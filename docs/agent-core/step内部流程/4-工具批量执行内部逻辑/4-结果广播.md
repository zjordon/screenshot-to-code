# 结果广播 — setCode 与 toolResult 消息

> 源码: `backend/agent/engine.py:305-323`

### 📋 **方法作用**

把工具执行结果分两路广播：产物变更走 `setCode` 全量更新前端代码区；执行摘要走 `toolResult` 关闭前端活动条目。并把本调用组装进 `ExecutedToolCall` 供回填。

---

### 🔄 **主要逻辑流程**

#### **1️⃣ 产物广播（第 305-310 行）**

```python
if tool_result.updated_content:
    await self._send("setCode", tool_result.updated_content)
    if self.recorder is not None:
        self.recorder.record_set_code(len(tool_result.updated_content), "tool_result")
```

**✅ 有产物（create_file/edit_file）：**
- `updated_content` 是 file_state.content 的直通副本——前端全量替换；
- 记录源标记 `"tool_result"`（与 stream_preview / finalize 构成三个记录源）。

**❌ 无产物（图片/素材/截图类工具）：**
- 跳过 setCode——这些工具不改主文件，其视觉反馈走 multimodal_parts 进会话（给模型看）而非前端代码区。

#### **2️⃣ 结果摘要广播（第 312-320 行）**

```python
await self._send(
    "toolResult",
    data={
        "name": tool_call.name,
        "output": tool_result.summary,     # 摘要，非完整 result
        "ok": tool_result.ok,
    },
    event_id=tool_event_id,                 # 与 toolStart 同 ID → 前端关闭条目
)
```

**关键参数说明：**
| 字段 | 来源 | 前端用途 |
|------|------|---------|
| `output` | `tool_result.summary` | 活动条目展开后的详情（diff/URL 列表/截图缩略） |
| `ok` | `tool_result.ok` | 条目成败着色 |
| `eventId` | 同 toolStart | AgentActivity 把条目从 running 置为 done/error |

#### **3️⃣ 组装执行记录（第 321-323 行）**

```python
executed_tool_calls.append(
    ExecutedToolCall(tool_call=tool_call, result=tool_result)
)
```

- 供 Phase 5 的 `append_tool_results` 整体写回会话（含完整 result 与图片）。

---

### 🎯 **设计亮点**

1. **双投影分轨**：同一结果的 `result`（全量，回填给模型）与 `summary`（截断，展示给前端）在此分道——WebSocket 载荷与 LLM 上下文各取所需。
2. **三个 setCode 记录源**：`stream_preview` / `tool_result` / `finalize`——run.json 重放时可区分内容到达路径。

---

### 📊 **返回值结构**

| 消息 | 载荷 | 触发条件 |
|------|------|---------|
| `setCode` | `{value: 完整HTML}` | updated_content 非空 |
| `toolResult` | `{data:{name, output:summary, ok}}` | 恒发（每个工具都有终态） |

---

### 💡 **典型使用场景**

- create_file：setCode（全量新内容）+ toolResult（path/长度/预览）。
- edit_file：setCode（编辑后全文）+ toolResult（diff + firstChangedLine——前端可高亮变更行）。
- screenshot_preview：仅 toolResult（摘要含内联 data URL 缩略图，前端可见自检截图）。

---

### 🔗 **与其他方法的协作**

```
tool_result
  ├── updated_content ──→ setCode ──→ 前端 PreviewPane（200ms 节流写 iframe）
  ├── summary + ok ────→ toolResult ─→ 前端 AgentActivity（关闭条目）
  └── 与 tool_call 组装 → ExecutedToolCall
                             │
                             ▼
              Phase 5 append_tool_results（result 全量 + 图片进会话）
```
