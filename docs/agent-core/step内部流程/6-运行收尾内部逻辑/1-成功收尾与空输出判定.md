# 成功收尾与空输出判定 — `EmptyOutputError` 的产生点

> 源码: `backend/agent/engine.py:354-360`；异常定义 `engine.py:25-35`

### 📋 **方法作用**

循环正常返回后的质检：产物非空才落盘 completed 并返回；空产物升级为可重试失败——防止"绿色空文件"污染下游。

---

### 🔄 **主要逻辑流程**

#### **1️⃣ 空输出判定（第 355-357 行）**

```python
result = await self._run_with_session(session)
if not result:
    raise EmptyOutputError()
```

**验证逻辑：**
- `not result` 即空串——三个来源都可能为空：模型只跑工具没写文件、正文剥不出 HTML、file_state 从未写入。

#### **2️⃣ 为什么空输出必须是错误（异常 docstring，第 25-35 行）**

```python
class EmptyOutputError(Exception):
    """Raised when a run finishes without producing any HTML.

    Some models (observed: gemini-3.6-flash) occasionally run asset tools
    and then stop without calling create_file. Treating that as success
    poisons evals: the run looks green, diff mode skips it forever, and
    the output file is empty. Raising makes it a normal, retryable failure.
    """
```

**📝 三重危害（若按成功处理）：**
| 危害 | 机制 |
|------|------|
| 评测"绿"但空 | run 状态 completed，分数录入却是空文件 |
| diff 模式永久跳过 | eval runner 以"已完成的输出文件"判断跳过——空文件占位后永不重跑 |
| 用户拿到空白变体 | 前端渲染空 iframe |

#### **3️⃣ 成功落盘（第 358-360 行）**

```python
if self.recorder is not None:
    await self.recorder.record_run_end("completed", final_html=result)
return result
```

- `record_run_end("completed")` 触发 final.html 落盘、自包含快照、SQLite 终态更新、易失资产收割（gather 后台任务）。

---

### 🎯 **设计亮点**

1. **失败语义细分**：EmptyOutput（可重试）vs Budget（不重试）vs 轮次耗尽（可重试）——eval runner 按异常类型制定重试策略的依据。
2. **质检在出口不在过程**：不试图在循环里检测"模型可能不写了"，只在终局判定——简单且无中间误杀。

---

### 📊 **返回值结构**

| 字段 | 类型 | 说明 |
|------|------|------|
| 成功 | `str` | 最终 HTML，一路返回到编排层（setCode + variantComplete） |
| 空产物 | `EmptyOutputError` | 固定文案 "Generation finished without producing any output." |

---

### 💡 **典型使用场景**

- gemini-3.6-flash 偶发"跑完 extract_assets 就停"——本判定把它变成 eval 里的一次普通重试而非永久占位。

---

### 🔗 **与其他方法的协作**

```
_run_with_session 返回 str
        │
        ├── 空 ──→ EmptyOutputError ──→ Phase 6-② 兜底
        │
        └── 非空 ──→ record_run_end("completed")
                      ├── final.html / final_selfcontained.html
                      ├── run.json + SQLite UPDATE
                      └── 后台资产任务 gather
                            │
                            ▼
                  _run_variant → setCode + variantComplete
```
